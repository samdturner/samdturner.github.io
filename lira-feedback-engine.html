Architecture, v2

Adding resiliency

Where we started: the web server graded the interview inside the request.

Grade in a background job. Ack the webhook in milliseconds, then take as long as grading needs.

503 from Gemini

Retry with backoff, cap 5. They arrive in bursts and clear within seconds.

LLM provider outage

Fall back to the second provider. One can be out for an hour; both rarely are.

Webhook delivered twice

Idempotent. The second delivery is a no-op.

Near-empty transcript

Handle it in the prompt. Return a “nothing to grade” message.
